# GOF CSC1031

## Description
This directory contains implementations of OOP design patterns studied in the ***CSC1031*** class. The patterns follow the concepts described by the Gang of Four and are implemented primarily in Java as part of coursework practice and experimentation.

## Patterns

### Creational
Creation design patterns focus on object creation.
- [Singleton](https://github.com/letv1nnn/computer-science/blob/main/programming/gof-csc1031/singleton/Singleton.java) - solves the problem of ensuring there's only instance of a class globally.
- [Factory Method](https://github.com/letv1nnn/computer-science/blob/main/programming/gof-csc1031/factory-method/FactoryMethod.java) - provides an interface for creating objects in a superclass, but allows subclasses to alter the type of objects that will be created.

### Structural
Structural design pattens focus on class and object composition.
- [Adapter](https://github.com/letv1nnn/computer-science/blob/main/programming/gof-csc1031/adapter/Adapter.java) - allows two incompatible interfaces to work together.
- [Decorator](https://github.com/letv1nnn/computer-science/blob/main/programming/gof-csc1031/decorator/Decorator.java) - lets you attach new behaviors to objects by placing these objects inside special wrapper objects that contain the behaviors ("add features at runtime like layers").

### Behavioral
Behavioral design patterns focus on communication between objects.
- [Mediator](https://github.com/letv1nnn/computer-science/blob/main/programming/gof-csc1031/mediator/Mediator.java) - lets you reduce dependencies between objects. The pattern restricts  direct communications between the objects and forces them to collaborate only via a mediator object.
- [Memento](https://github.com/letv1nnn/computer-science/tree/main/programming/gof-csc1031/memento) -  saves and restores an object's state without breaking encapsulation.
- [Observer](https://github.com/letv1nnn/computer-science/blob/main/programming/gof-csc1031/observer/Observer.java) - lets you define a subscription mechanism to notify multiple objects about any events that happen to the object they are observing.
- [Strategy](https://github.com/letv1nnn/computer-science/blob/main/programming/gof-csc1031/strategy/Strategy.java) - lets you define a family of algorithms, put each of them into a separate class, and make their objects interchangeable.
- [Template Method](https://github.com/letv1nnn/computer-science/blob/main/programming/gof-csc1031/template-method/TemplateMethod.java) - defines the skeleton of an algorithm in the superclass but lets subclasses override specific steps of the algorithm without changing its structure.
